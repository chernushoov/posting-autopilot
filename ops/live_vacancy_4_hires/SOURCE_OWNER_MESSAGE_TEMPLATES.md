# Source Owner Message Templates

Use these when posting depends on another person or admin.

## 1. Ask for posting permission

```text
Здравствуйте. У нас есть актуальная вакансия по Израилю и хотим уточнить, можно ли разместить её у вас.

Если можно, отправим короткий текст в вашем формате.
```

## 2. Send the compact post

```text
Готовый текст для размещения:

[PASTE FACEBOOK GROUP OR TELEGRAM COMPACT POST]

Если нужен другой формат или сокращение, адаптируем сразу.
```

## 3. Follow-up if no answer

```text
Здравствуйте. Напоминаю по размещению вакансии.

Если публикация возможна, пришлю финальный текст сразу.
Если нет, просто дайте короткий ответ, чтобы мы не держали источник в рабочем списке.
```
