# Bug Report Template

Send this on WhatsApp or paste into a message when something doesn't work.

---

## Report Format

```
WHAT I TRIED TO DO:
(e.g., "Generate a post for a QA Engineer vacancy")

WHAT HAPPENED:
(e.g., "Page showed a spinning wheel for 30 seconds, then nothing appeared")

WHAT I EXPECTED:
(e.g., "A Hebrew post should have appeared")

WHICH STEP:
(1 = Enter vacancy / 2 = Generate post / 3 = Pick groups / 4 = Post to groups / 5 = Track results / 6 = Other)

SCREENSHOT:
(Attach if possible — photo of the screen is fine)

DEVICE + BROWSER:
(e.g., "Chrome on Windows laptop" or "Safari on Mac")

HOW BAD IS IT:
🔴 Can't continue at all
🟡 Annoying but I found a workaround
🟢 Minor — cosmetic or small issue
```

---

## Quick Examples

**Blocking bug:**
```
WHAT I TRIED TO DO: Copy the post to clipboard
WHAT HAPPENED: Nothing copied — pasted empty text in Facebook
WHAT I EXPECTED: Post text on my clipboard
WHICH STEP: 4
HOW BAD IS IT: 🔴
```

**Annoying bug:**
```
WHAT I TRIED TO DO: Generate post with "Casual" tone
WHAT HAPPENED: Post came out in English instead of Hebrew
WHAT I EXPECTED: Hebrew post
WHICH STEP: 2
HOW BAD IS IT: 🟡
```

**Minor issue:**
```
WHAT I TRIED TO DO: Mark a group as "Done"
WHAT HAPPENED: Button worked but no green checkmark appeared
WHAT I EXPECTED: Visual confirmation
WHICH STEP: 4
HOW BAD IS IT: 🟢
```
