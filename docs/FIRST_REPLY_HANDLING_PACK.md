# First Reply Handling Pack

---

## How to Use This

When a reply comes in:
1. Classify it (table below)
2. Respond within 5 minutes if WhatsApp, 2 hours if email
3. Use the exact response text — modify only [bracketed] sections
4. If their reply doesn't fit neatly, pick the closest category

---

## 10 Response Types

### 1. "כן, מעניין" / "Yes, interested"

**Classification:** HOT
**Best next action:** Book demo immediately. Do not explain more over text.
**Response:**
```
מעולה! 🙏

מתי נוח ל-5 דקות? אני מראה שיתוף מסך ואתה רואה בדיוק איך זה עובד.

יש לי פנוי:
• [tomorrow] ב-10:00
• [tomorrow] ב-14:00
• [day after] ב-11:00

מה עדיף?
```
**If they don't pick a time:**
```
מה לגבי [specific day] ב-10:00? 5 דקות ונסיים.
```

---

### 2. "מה בדיוק אתם עושים?" / "What exactly do you do?"

**Classification:** WARM — curious, needs clarity
**Best next action:** Explain in 3 lines max, then push for demo.
**Response:**
```
בקצרה:

1️⃣ AI כותב פוסט בעברית למשרה שלך — 3 שניות
2️⃣ בוחר קבוצות מספרייה חכמה עם דירוגים
3️⃣ מפרסם ידנית — 15 שניות לקבוצה — הכל נעקב

בלי בוטים, בלי אוטומציה בפייסבוק. אתה תמיד מפרסם בעצמך.

שווה 5 דקות דמו? אראה לך בשיתוף מסך.
```
**If they ask more questions instead of booking:**
```
אני יכול לענות על הכל — אבל 5 דקות שיתוף מסך מראה יותר ממאה הודעות 😊 מתי נוח?
```

---

### 3. "כמה זה עולה?" / "How much does it cost?"

**Classification:** WARM — buying signal (they're qualifying themselves)
**Best next action:** Answer briefly, redirect to demo.
**Response:**
```
14 יום ניסיון חינם, בלי כרטיס אשראי.

אחרי זה מ-499 ₪/חודש, לפי מספר מגייסים.

אבל שווה לראות קודם — 5 דקות דמו ותדע אם רלוונטי. מתי נוח?
```
**If they push back on price:**
```
זה פחות מיום עבודה של מגייס — וחוסך 2-3 שעות ביום. אבל הפיילוט חינם, אז אפשר לראות אם מתאים בלי סיכון.
```

---

### 4. "מעניין, אבל אני עסוק עכשיו" / "Interesting but busy now"

**Classification:** WARM — real interest, bad timing
**Best next action:** Respect it, but lock a specific time.
**Response:**
```
לגמרי מבין 👍

מתי יהיה רגע? אני גמיש.

אפילו 5 דקות [next week] — אפשר?
```
**If they stay vague:**
```
אין בעיה. אני אשלח תזכורת ב[specific day — pick one 5 days out]. יתאים?
```
**Then:** Set reminder in your sheet. Follow up on that exact date.

---

### 5. "תחזור אליי בעוד X" / "Ask me later"

**Classification:** COOL — not rejecting, but not engaging
**Best next action:** Confirm the exact date. Don't push.
**Response:**
```
בסדר גמור! מתי בדיוק נוח שאחזור?

א. שבוע הבא
ב. עוד שבועיים
ג. חודש
```
**After they pick:** Set the exact date. Follow up on that date with:
```
היי [שם], מחזיר כמו שסיכמנו 😊 יש 5 דקות לדמו מהיר?
```

---

### 6. "שלח לי חומר / פרטים" / "Send me details"

**Classification:** WARM-COOL — may be genuine, may be a brush-off
**Best next action:** Send a 2-line summary, then push for demo.
**Response:**
```
בשמחה. הנה בקצרה:

Recruit Autopilot — כלי לפרסום משרות בקבוצות פייסבוק:
✅ AI כותב פוסט בעברית — 3 שניות
✅ ספריית קבוצות עם דירוגים
✅ מעקב מלא — איזה קבוצה הביאה קו"ח
✅ בלי אוטומציה — אפס סיכון חסימה

14 יום ניסיון חינם.

אבל 5 דקות דמו מראה הכל יותר טוב מטקסט. מתי נוח?
```
**If they don't respond to this within 24h:** one follow-up:
```
היי [שם], ראית את הפרטים? שווה 5 דקות?
```

---

### 7. "כבר יש לנו תהליך" / "We already have a process"

**Classification:** WARM — potential objection or real satisfaction
**Best next action:** Acknowledge, then probe.
**Response:**
```
מצוין שיש תהליך 👍

שאלה אחת — יש לכם מעקב על איזה קבוצות מביאות קו"ח?

הכלי שלנו מוסיף בדיוק את זה — בלי לשנות את התהליך, רק להוסיף מעקב ומהירות.

שווה 5 דקות לראות?
```
**If they say their process is fine:**
```
הבנתי. אם משהו ישתנה — אני כאן. בהצלחה! 🙏
מכירים סוכנות שכן תרצה לשפר את הפרסום בפייסבוק?
```

---

### 8. "אנחנו לא מפרסמים בפייסבוק" / "We don't post on Facebook"

**Classification:** NOT FIT
**Best next action:** Thank, ask for referral, close.
**Response:**
```
הבנתי, תודה על התגובה! 🙏

שאלה אחרונה — מכירים סוכנות גיוס שכן מפרסמת בקבוצות פייסבוק? אשמח להפניה.
```
**Then:** Mark as "Lost — Not Fit" in sheet. Move on.

---

### 9. "תראה לי דמו" / "Show me a demo"

**Classification:** HOT
**Best next action:** Book immediately. Same as response type #1.
**Response:**
```
בשמחה! מתי נוח?

יש לי:
• [tomorrow] ב-10:00
• [tomorrow] ב-14:00
• [day after] ב-11:00

זה 5 דקות — שיתוף מסך ואני מראה.
```

---

### 10. "לא רלוונטי" / "Not relevant"

**Classification:** CLOSED
**Best next action:** Thank, referral ask, archive.
**Response:**
```
בסדר גמור, תודה! 🙏

מכירים מישהו שכן מפרסם בקבוצות פייסבוק? אשמח להכרות.

בהצלחה!
```
**Then:** Mark as "Lost — Not Interested." Archive. Do not follow up.

## Quick Classifier

When a reply comes in, scan this table:

| If they say... | Type | Do... |
|---|---|---|
| כן / מעניין / אפשר | HOT | Book demo NOW |
| תראה לי / דמו / אני רוצה לראות | HOT | Book demo NOW |
| מה זה / מה אתם עושים / איך עובד | WARM | 3-line explain → demo push |
| כמה עולה / מחיר | WARM | Brief answer → demo push |
| שלח פרטים / חומר | WARM-COOL | Send summary → demo push |
| עסוק / אין זמן | WARM | Lock specific future time |
| תחזור בעוד X | COOL | Confirm date, set reminder |
| יש לנו תהליך / כבר עושים | WARM | Probe for tracking gap |
| לא מפרסמים בפייסבוק | NOT FIT | Referral ask → close |
| לא רלוונטי / לא מעוניין | CLOSED | Referral ask → archive |

## Response Speed Rules

| Channel | Target Response Time |
|---|---|
| WhatsApp | Under 5 minutes |
| Facebook messenger | Under 30 minutes |
| Email | Under 2 hours |
| LinkedIn | Under 4 hours |

**A fast reply signals professionalism and creates momentum. Slow replies kill warm leads.**
