# Sunday Execution Checklist

## Pre-launch
- Confirm the client sent all vacancy facts
- Fill `vacancy_intake_template.json`
- Confirm vacancy body is final
- Confirm screening questions are final
- Confirm first-wave sources are selected
- Confirm who is posting manually
- Confirm where metrics will be logged

## Vacancy finalization
- Check role title
- Check hires needed
- Check city / location
- Check pay
- Check schedule
- Check must-have requirements
- Check legal / document requirement
- Check benefits
- Check urgency / start date
- Check apply path

## Launch
- Post to first Telegram manual/userbot-assisted sources
- Post to Facebook page
- Post to selected Facebook groups
- Record every post in `pilot_metrics.csv`

## Tracking
- Count responses
- Count screenings started
- Count screenings completed
- Count qualified candidates
- Count interview-ready candidates
- Note any friction or source failure

## End of day
- Add a `daily_rollup` row in `pilot_metrics.csv`
- Update `case_study_capture.json`
- Mark what worked
- Mark what failed
- Mark what is blocked for next day
