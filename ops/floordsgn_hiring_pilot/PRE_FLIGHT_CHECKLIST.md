# FLOORdsgn — pre-flight чеклист перед живым демо (TG-найм мастера)

> Демо = ты в сторис/рилсе показываешь, **КАК работает автопилот**: он постит вакансию
> в TG-группы → ловит мастера → 🔥-лид с телефоном падает тебе в Telegram.
> **Instagram — это твоя сцена (где ты рассказываешь), а НЕ куда постит продукт.**
> Продукт постит только в **Telegram-группы** (и FB вручную). В инсту он не умеет — не обещай этого.

⚠️ **Где это запускать:** живой инстанс крутится на **Desktop iMac (:8000)** (`recruit-autopilot-core`).
Канонический git-фикс двойного клика лежит в `~/Work/02-Projects/posting-autopilot`
(ветка `fix/double-click-post-guard`). **Если демо-инстанс — другой кодовой базы, перенеси туда
guard `_recent_inflight_run` руками, либо просто жми «Run now» ОДИН раз (см. п.5).**

---

## 0. Поднято ли всё (один раз, до всего)
- [ ] `redis` и `postgres` живы.
- [ ] Подняты 4 процесса: **web + worker + scheduler + bot**. Без worker/redis «Запустить» = 500.
- [ ] Юзербот залогинен: файл сессии `data/tg_sessions/company_<id>.session` существует и валиден.

## 1. 🔥 ТИХИЙ УБИЙЦА №1 — уведомление о горячем лиде
Кульминация демо. Если не настроено — кандидат **скорится, но 🔥 тебе НЕ придёт** (бот молча
напишет в лог «no notify chat configured»).
- [ ] Задан `RECRUIT_OPERATOR_NOTIFY_CHAT` = твой Telegram chat_id (или `owner_id` у компании).
- [ ] **Зелёная проверка:** прогони `python scripts/simulate_hot_lead.py` (он есть в репо) —
      убедись, что 🔥-сообщение реально пришло тебе в Telegram. Если не пришло — демо без этого не начинай.

## 2. 🔥 ТИХИЙ УБИЙЦА №2 — юзербот / сессия
- [ ] Сессия не слетела (см. п.0). Если слетела — постинг **молча не идёт**, в группах пусто.
- [ ] У компании заданы `tg_api_id` + `tg_api_hash` (иначе пойдёт через Bot API — а бот должен
      быть админом в группе, иначе 403).

## 3. 🔥 ТИХИЙ УБИЙЦА №3 — группы не проверены
- [ ] В `/sources` добавлены реальные израильские TG-группы (стройка/работа/ремонт).
- [ ] Каждая нажата **«Проверить»** и показывает READY. Непроверенная → пост **молча не уходит**
      (`"destination is not marked ready. Run Check first."`).
- [ ] Капы понятны: **10/час, 50/день, ночь 23:00–07:00 пауза.** Демо — днём.

## 4. Контент вакансии
- [ ] Прогнал `seed_floor_installer.py` → вакансия FLOORdsgn (HE+RU) заведена.
- [ ] В вакансии заполнены поля `<<...>>`: **оплата, телефон/WhatsApp компании.**
- [ ] Приложено **1 хорошее фото** готового пола (карусель не поддерживается — одно сильное фото).
- [ ] Иврит из `POST_COPY.md` прогнан глазами носителя (род м/ж, идиомы).
- [ ] Имя бота в apply-ссылке актуально (в доках стоит `@AutopillotRecruit_bot` — **подтверди**).

## 5. РЕПЕТИЦИЯ вслепую (за 15 мин до записи, НЕ на камеру)
- [ ] Создай кампанию на 1–2 **тестовые** группы (или свою группу), нажми **Run now ОДИН раз**.
- [ ] Сам пройди как кандидат: жми apply-ссылку → ответь на 4 вопроса → дай телефон.
- [ ] Убедись: пост появился + 🔥-лид с телефоном реально упал тебе в Telegram. **Это и есть весь продукт.**
- [ ] ⚠️ **Жми Run now строго один раз.** Двойной клик = пост дважды в каждую группу
      (guard добавлен в канон-репо, но на демо-инстансе его может не быть).

## 6. Во время записи
- [ ] Один клик «Run now». Смотри лог назначений внизу (posted/failed по каждой группе).
- [ ] Показывай 🔥-лид в своём Telegram — это сильнейший кадр.
- [ ] Постишь с личного TG-аккаунта = **ненулевой риск бана**. Для демо хватит 2–5 групп, не 50.

## 7. Что НЕ говорить вслух (сгоришь на несоответствии)
- ❌ «ИИ ведёт диалог / переписывается с кандидатом» — нет, это скриптовая анкета из 4 вопросов;
      LLM зовётся один раз в конце для скоринга. (Лендинг это переобещает — поправить отдельно.)
- ❌ «Постим в Instagram» — продукт не умеет. Инста = твоя витрина.
- ❌ «Ловим отклики где угодно» — ловятся только прошедшие по apply-ссылке в личку бота;
      ответы в комментариях группы теряются (подбирай руками — это норм на пилоте).
- ✅ Говори правду, которая сильная: **«Одно объявление → десятки TG-групп в один клик →
      ИИ-скоринг откликов → готовый горячий лид с телефоном и выжимкой мне в Telegram.»**

## 8. Если что-то отвалилось на демо — быстрая диагностика
- Пост не появился в группе → группа не READY (п.3) или сессия слетела (п.2).
- 🔥 не пришёл → `RECRUIT_OPERATOR_NOTIFY_CHAT` не задан (п.1).
- «Запустить» даёт 500 → не поднят worker/redis (п.0).
