# Candidate Message Templates

Use these when manual or assisted handling is needed.

## 1. First reply

```text
Здравствуйте. Спасибо за отклик на вакансию `[ROLE TITLE]`.

Чтобы быстро понять, подходите ли вы, ответьте, пожалуйста, на несколько коротких вопросов.
```

## 2. Fast screening request

```text
Пожалуйста, ответьте коротко:

1. В каком городе вы живёте?
2. Есть ли у вас опыт по этой работе?
3. Есть ли у вас право работать в Израиле?
4. Когда можете выйти?
5. Подходит ли вам график `[SCHEDULE]`?
```

## 3. Passed to next step

```text
Спасибо. По первым ответам вы подходите под вакансию `[ROLE TITLE]`.

Следующий шаг: передаём ваш отклик рекрутеру на следующий контакт / интервью.
```

## 4. Need clarification

```text
Спасибо. Чтобы двигаться дальше, нужно уточнить один момент:

`[QUESTION / CLARIFICATION]`
```

## 5. Rejection

```text
Спасибо за отклик.

Сейчас эта вакансия вам не подходит по требованиям или условиям. Если появится более подходящая позиция, мы сможем вернуться к вашему профилю.
```

## 6. Interview handoff

```text
Вы прошли первичный отбор по вакансии `[ROLE TITLE]`.

Следующий шаг: `[INTERVIEW OWNER / CONTACT]` свяжется с вами для следующего этапа.
Пожалуйста, оставайтесь на связи.
```
