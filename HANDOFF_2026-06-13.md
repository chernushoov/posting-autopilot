### Как деплоить (ВАЖНО: НЕ запускать `deploy-hetzner.sh` как есть)
Скрипт `wait_for_service`-ит bot+listener, которые не могут стать healthy без секретов → падает. Гонять compose вручную:
```bash
# 1) доставить канон-код на сервер (с машины где есть репо):
git -C <repo> archive HEAD | ssh -i ~/.ssh/posting_autopilot_hetzner root@167.233.98.210 'tar -x -C /opt/posting-autopilot'
# 2) на сервере:
cd /opt/posting-autopilot
export APP_ENV_FILE=.env.prod APP_RUNTIME_ENV_FILE=.env.runtime
C="docker compose --env-file .env.prod -f docker-compose.yml -f docker-compose.prod.yml"
$C build
$C up -d postgres redis
$C run --rm web python -m scripts.migrate     # аддитивная миграция
$C up -d web worker scheduler caddy           # НЕ bot/listener пока нет секретов
```

## Что ПЕНДИНГ (по приоритету) + что именно нужно

### 1. Подключить каналы (СЕЙЧАС) — нужны 4 значения от владельца
- **Telegram API (вход по номеру):** my.telegram.org → API development tools → app →
  - `RECRUITBOT_TG_API_ID` (число), `RECRUITBOT_TG_API_HASH` (строка)
- **Facebook App:** developers.facebook.com → Settings → Basic →
  - `FB_APP_ID`, `FB_APP_SECRET`
- Действие: вписать в `/opt/posting-autopilot/.env.prod`, перезапустить web/worker/scheduler, проверить что `/connect/telegram` реально шлёт код в Telegram.
- ⚠️ Симулятора/демо-подключения в коде НЕТ — нужны настоящие креды (владелец выбрал реальные креды, не демо-режим).
- ⚠️ FB: постинг в группы/Marketplace без официального API → серая зона, делать аккуратно.

### 2. Bot E2E (диалог бота с кандидатом)
- `RECRUITBOT_TELEGRAM_BOT_TOKEN` (=`TELEGRAM_BOT_TOKEN` зеркало) от BotFather.
- AI-ключ: `RECRUITBOT_AI_API_KEY`/`AI_API_KEY` (или `RECRUITBOT_AI_PROVIDER=stub` + `ALLOW_STUB_AI=1` для keyword-fallback).
- Затем `$C up -d bot`. **Только сервис `bot`** требует токен+AI в проде (env_guard); web/worker/scheduler — нет.

### 3. Воронка входящих (Phase-2 listener)
- Нужен вход **личным TG-аккаунтом** владельца (Telethon userbot, серая зона). Затем `$C up -d listener`.

### 4. Stripe (оплата)
- `BILLING_ENABLED=true` + `STRIPE_*` ключи (см. `STRIPE_RUNBOOK.md`). Сейчас `BILLING_ENABLED=false`.
