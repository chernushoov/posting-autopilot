# Candidate Follow-up Templates

Use these if the candidate replied once but did not finish the screening or did not confirm the next step.

## 1. Screening reminder

```text
Здравствуйте. Напоминаю по вакансии `[ROLE TITLE]`.

Чтобы мы могли продолжить, ответьте, пожалуйста, на оставшиеся короткие вопросы.
```

## 2. Follow-up after partial answers

```text
Спасибо. Нам нужно уточнить ещё один момент, чтобы двигаться дальше:

`[QUESTION]`
```

## 3. Interview confirmation reminder

```text
Здравствуйте. Подтвердите, пожалуйста, что вы всё ещё готовы идти дальше по вакансии `[ROLE TITLE]`.

Если да, мы передаём вас на следующий шаг.
```

## 4. Close inactive lead

```text
Если вакансия для вас ещё актуальна, напишите нам.

Если ответа не будет, мы временно закроем отклик по этой позиции.
```
