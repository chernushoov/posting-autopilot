# Recruiter Handoff Template

Use this when a candidate is qualified and needs to move to the recruiter or client-side next step.

```text
Кандидат прошёл первичный отбор по вакансии `[ROLE TITLE]`.

Данные для передачи:
- Имя: `[NAME]`
- Контакт: `[CONTACT]`
- Источник: `[SOURCE]`
- Язык: `[LANGUAGE]`
- Город: `[CITY]`
- Краткий итог: `[WHY THIS CANDIDATE FITS]`
- Ограничения / риски: `[RISKS OR NONE]`
- Следующий шаг: `[CALL / INTERVIEW / CLIENT REVIEW]`

Пожалуйста, возьмите кандидата в работу и обновите статус после следующего контакта.
```

## Handoff rule
- Do handoff only after the minimum screening is complete.
- Always include the source and the concrete next step.
- Log the handoff in `candidate_pipeline.csv` and `interview_followup_log.csv`.
