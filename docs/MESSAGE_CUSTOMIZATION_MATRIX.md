## WhatsApp First Touch

### Segment A — Confirmed Poster, Have WhatsApp (BEST)
```
היי [שם],

ראיתי את הפוסטים שלכם בקבוצת [שם קבוצה] 👋

בניתי כלי שעושה את זה 5x יותר מהר:
🔹 AI כותב פוסט בעברית — 3 שניות
🔹 ספריית קבוצות עם דירוגים
🔹 מעקב מלא — מאיזה קבוצה הגיעו קו"ח

בלי בוטים. בלי סיכון חסימה.

יש דמו של 5 דקות — מעניין?
```

```
היי [שם],

ראיתי שאתם מפרסמים הרבה משרות בקבוצות — [שם קבוצה] ועוד כמה.

בניתי כלי שחוסך שעות ביום על זה:
✅ AI כותב את הפוסט

✅ 15 שניות לפרסם בקבוצה
✅ מעקב — איזה קבוצה הביאה קו"ח

5 דקות דמו — מעניין?
```

### Segment A — Variant for Copy-Paste Poster
```
היי [שם],

שמתי לב שאתם מפרסמים אותו פוסט בכמה קבוצות — זה לוקח המון זמן, נכון?

AI שלנו כותב פוסט ייחודי לכל קהל — 3 שניות. פלוס ספריית קבוצות עם מעקב.

בלי אוטומציה, בלי סיכון.

רוצה לראות?
```

### Segment C — Unconfirmed, Qualifying
```
היי [שם],

אני רואה שאתם מגייסים ב[תחום/עיר].

שאלה מהירה — מפרסמים משרות בקבוצות פייסבוק?
```

## Quick Personalization Variables

| Variable | Where to Find | Paste Into Message |
|---|---|---|
| `[שם]` | Facebook profile / LinkedIn / lead sheet | First line |
| `[שם קבוצה]` | Your lead sheet "Source" column | First or second line |
| `[תחום]` | Observed from their posts (tech/service/etc.) | Segment C messages |
| `[עיר]` | Observed from posts or agency location | Segment C messages |

**You only need [שם] + [שם קבוצה] for Segment A messages. That's 10 seconds of personalization.**

## Objection Micro-Responses

Keep these under 2 lines. Copy-paste directly into WhatsApp.

### "What is this?"
```
כלי שעוזר למגייסים לפרסם משרות בקבוצות פייסבוק — מהר יותר, עם מעקב, בלי סיכון חסימה. אפשר דמו של 5 דקות?
```

### "How much?"
```
14 יום ניסיון חינם, בלי כרטיס אשראי. אחרי זה מ-499 ₪/חודש. אבל שווה לראות קודם — 5 דקות דמו?
```

### "We use an autoposter"
```
עובד עד שפייסבוק תופס 😬 אנחנו עושים את אותו דבר מהר — בלי הסיכון. פלוס מעקב שאין לאף אוטופוסטר. שווה 5 דקות?
```

### "We don't use Facebook groups"
```
הבנתי, תודה! מכירים סוכנות גיוס שכן מפרסמת בקבוצות? אשמח להפניה 🙏
```

### "Not now"
```
בסדר גמור. מתי נוח שאחזור? חודש? רבעון?
```

### "Send me info"
```
בשמחה — אבל דמו של 5 דקות מראה יותר מכל מסמך. אפשר מחר? מתי נוח?
```

### "How does this work?"
```
בקצרה: AI כותב פוסט בעברית → בוחרים קבוצות מספרייה → מפרסמים ידנית (15 שניות לקבוצה) → הכל נעקב. רוצה לראות? 5 דקות.
```

### "Is this a bot?"
```
לא. בשום שלב אנחנו לא מפרסמים במקומך. AI כותב את הטקסט, אתה מפרסם. אפס אוטומציה בפייסבוק.
```

## Demo Booking Push Lines

Use when they're interested but not committing to a time.

### Soft Push
```
מתי נוח ל-5 דקות השבוע? אני גמיש.
```

### Direct Push
```
יש לי פנוי מחר ב-10:00 או 14:00. מה עדיף?
```

### Urgency Push
```
אנחנו לוקחים 20 סוכנויות לפיילוט הראשון. יש לי עוד כמה מקומות. מתי נוח?
```

### Lowering the Bar
```
זה ממש 5 דקות — שיתוף מסך ואני מראה. אם לא רלוונטי, תדע תוך דקה.
```
