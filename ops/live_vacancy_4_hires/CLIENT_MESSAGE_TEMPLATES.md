# Client Message Templates

## 1. Initial vacancy intake message

Use this first.

```text
Чтобы запустить вакансию быстро и без лишних уточнений, пришлите, пожалуйста, всё в одном сообщении:

1. Название вакансии
2. Сколько человек нужно
3. Город / локация работы
4. Оплата
5. График / смены
6. Главные требования
7. Нужны ли документы / разрешение на работу
8. Есть ли бонусы / преимущества
9. Насколько срочно нужен выход
10. Какие языки важны
11. Куда вести отклик
12. Кто контактное лицо со стороны клиента

Можно просто ответить в таком формате:

- Вакансия:
- Кол-во:
- Город:
- Оплата:
- График:
- Требования:
- Документы / статус:
- Бонусы:
- Срочность:
- Язык:
- Путь отклика:
- Контакт:
- Комментарий:
```

## 2. Missing-info follow-up

Use only if the client sends partial data.

```text
Спасибо. Чтобы мы могли запустить размещение без ошибок, не хватает ещё вот этих пунктов:

- [MISSING FIELD 1]
- [MISSING FIELD 2]
- [MISSING FIELD 3]

Как только это пришлёте, сразу соберём финальный текст и начнём размещение.
```

## 3. Launch confirmation message

Use when the vacancy is ready to go live.

```text
Вакансию собрали.

Сейчас у нас готово:
- финальный текст вакансии
- вопросы для скрининга
- список первых источников для размещения
- трекинг ответов и кандидатов

Следующий шаг: запускаем первую волну размещений и начинаем фиксировать отклики.
```
