## ✅ Что РЕАЛЬНО работает

- Hebrew-RTL UI, онбординг-мастер, мультитенант, **самостоятельная регистрация открыта** (нет инвайт-гейта), CSRF, 14-дн триал.

- **Hot-lead сигнал РЕАЛЕН и подключён**: score≥40 + телефон → 🔥 в Telegram оператору + email + WhatsApp-ссылка.
- Дедуп по телефону («уже говорили, отказ»).
- Dockerfile готов к хосту; деплой на VPS за ~0.5–1 день.
- Реальные секреты НЕ в git. Stripe-код написан (правильный провайдер).

## 🚧 Три структурных блокера денег

### 1. Нет живого хоста (мех., ~1 день)
6-сервисный Docker-стек (web/worker/scheduler/bot/postgres/redis) — **Vercel невозможен**. Нужен VPS €4.5–12/мес (Hetzner/DO) + HTTPS (Caddy) + домен. Есть `/health` и smoke-скрипты.

### 2. Заплатить НЕЛЬЗЯ (мех., ~1–2 дня)
Stripe заимпортлен и код корректен, но **ноль конфигурации** — клик по тарифу уводит обратно на `/pricing?error=billing_not_configured`. Нет Stripe-аккаунта, нет Price-ID, нет env-переменных. Карту ввести негде.

### 3. Моат «ИИ ведёт диалог» ≈ 0% реален (продукт, недели)
Заявка продукта: ИИ сам переписывается с откликнувшимися. **Реальность: скриптовый FSM** — бот задаёт фиксированный список вопросов по очереди; LLM вызывается ОДИН раз в конце только чтобы выставить score+summary. Бот **не отвечает** на вопросы кандидата (`bot_faq_knowledge` хранится, но не используется). `operator_copilot.py` — НЕ ИИ (детерминированные подсказки). Самоописано в `KNOWN_LIMITATIONS.md:13`. Сигнал хэндоффа — реален; сам «диалог» — нет.

## 💣 Операционные мины (ломают «прямо сейчас»)

- **Нет Redis → «Запустить» даёт 500**, проверка TG-источника никогда не зеленеет (worker/queue импортит Redis; voor реального запуска нужны 4 процесса вверх).
- **Двойной постинг**: нет in-flight лока на «Run now», нет unique-constraint на `(run_key, source_id)`, TZ-баг в дневном капе (UTC vs Israel). Двойной клик → пост дважды в каждую группу.
- **INBOUND из групп/FB теряется**: нет Telethon-листенера, нет FB Messenger-хэндлера. Доходят только те, кто кликнул apply-ссылку и написал боту в ЛС. Израильские соискатели чаще отвечают В группе/в ЛС постера → **молча на пол**. Главная дыра воронки.
- Бот в compose `restart:"no"` → упал = скрининг встал молча, а посты продолжают лететь.
- Юзербот-массрассылка с личного аккаунта = реальный риск бана (капы глобальные, не на группу; задержку снизили 600→120с ради UX).

## Дорожная карта к первым деньгам (приоритеты)

**P0 — механика «можно купить» (~2–3 дня):**
1. VPS + Docker + HTTPS + домен (живой URL).
2. Stripe: аккаунт + 3 ILS-цены + env-переменные → кнопка тарифа доводит до карты.
3. Безопасность: сменить/выскрести админ-пароль, bcrypt, webhook-секрет.
4. Поднять Redis+worker+scheduler+bot, починить двойной постинг (лок + unique constraint).

**P0.5 — заткнуть дыру воронки (~2–4 дня):**
5. Либо добавить **Telethon-листенер** на входящие из групп, либо чётко вести весь трафик через apply-ссылку (она работает) и убрать обещание «ответят где угодно».

**P1 — построить моат (недели):**
6. Заменить FSM на настоящий LLM-цикл по ходам: отвечает на вопросы из FAQ, динамически дозадаёт квалификацию, учитывает hot/cold-критерии оператора, пишет настоящую выжимку диалога.
7. FB Messenger inbound-хэндлер (если оставляем FB).

**Альтернатива (быстрее всех к кэшу):** done-for-you пилот 1 рекрутёру — крутим на нашем сервере, где надо руками, берём деньги за результат; продукт-полировку делаем под реальную обратную связь.
