# First 30 Leads Execution Pack

---

## Segmentation Logic

Every lead falls into one of 4 segments based on two questions:

```
Q1: Did you SEE them posting in Facebook groups?
    YES → Confirmed Poster
    NO  → Unconfirmed

Q2: Do you have their WhatsApp / phone number?
    YES → Contactable
    NO  → Need Research
```

| Segment | Definition | Priority | Action |
|---|---|---|---|
| **A: Confirmed + Contactable** | Seen posting in FB groups AND have WhatsApp | 🔴 Contact TODAY | Personalized WhatsApp — reference the group |
| **B: Confirmed + Need Research** | Seen posting but no phone yet | 🟡 Research → Contact | Spend 3 min finding phone. If found → Segment A. If not → email/LinkedIn. |
| **C: Unconfirmed + Contactable** | Likely posts to FB (found via LinkedIn/Google) AND have phone | 🟡 Contact with qualifier | WhatsApp with qualifying question first |
| **D: Unconfirmed + Need Research** | Found via directory/referral, no confirmed FB activity, no phone | ⚪ Backfill only | Email if available. Otherwise skip. |

---

## Priority Order — Who to Message First

```
1st: All Segment A leads (confirmed posters with WhatsApp) — send today
2nd: Segment B leads that you upgraded to A after research — send today
3rd: Segment C leads (qualifying message) — send Day 2
4th: Segment D leads — email only, send Day 3 or skip
```

**Never message Segment C or D before finishing all Segment A leads.**

## How to Personalize Fast (30 Seconds Per Message)

### The 3 Variables That Matter

| Variable | Where to Find It | Time |
|---|---|---|
| **[שם]** — their first name | Facebook profile or post | 2 sec |
| **[שם קבוצה]** — the group where you found them | Your lead sheet "Source" column | 2 sec |
| **[what you noticed]** — one detail about their posting | Your lead sheet "Pain Signal" column | 5 sec |

### Personalization Examples

| What You Noticed | How to Use It |
|---|---|
| Same post in 5+ groups | "ראיתי שאתם מפרסמים באותו פוסט בכמה קבוצות" |
| Plain text, no formatting | "ראיתי את הפוסטים שלכם — AI יכול לעשות אותם הרבה יותר טוב" |
| Tech roles specifically | "ראיתי שאתם מגייסים לתחום ההייטק דרך קבוצות" |
| Multiple vacancies same day | "ראיתי שיש לכם כמה משרות פתוחות — הרבה פרסום ידני" |
| Posting in a specific city group | "ראיתי שאתם פעילים בקבוצות דרושים ב[עיר]" |

**Do NOT spend more than 30 seconds personalizing. The group name alone is enough personalization for wave 1.**

## What NOT to Say

| Never Say | Why |
|---|---|
| "אוטומציה" / "automation" | Triggers Facebook ban fear in the wrong direction. We're the opposite. |
| "בוט" / "bot" | Same reason. |
| "We post for you" / "אנחנו מפרסמים במקומכם" | We don't. The human always posts. |
| "AI replaces your recruiter" | Threatening. We help recruiters, not replace them. |
| "Free forever" / "חינם לתמיד" | It's a 14-day trial. Don't overpromise. |
| Technical jargon (API, NLP, algorithm) | They're recruiters, not engineers. |
| "I'm building a startup" | They don't care. Lead with their problem. |
| Anything about competitors by name | Looks petty. Focus on value. |
| Price in the first message | Too early. Qualify and demo first. |

## "Send Now" vs "Research More" Decision

| Situation | Decision |
|---|---|
| Have their name + WhatsApp + seen them in a group | ✅ Send now |
| Have their name + WhatsApp + found via LinkedIn (no FB confirmation) | ✅ Send now (qualifying message) |
| Have their name + agency + Facebook profile but no phone | ⏳ Spend 3 min researching phone. If found → send. If not → email/LinkedIn. |
| Have agency name only, no person | ⏳ Spend 2 min finding a person. If found → continue. If not → skip for now. |
| Only have a general company email (info@) | ⏳ Try to find a person. If not → send email but expect low response. |
| Can't find any contact after 5 min | ❌ Skip. Move to next lead. |

**Rule: if you've spent 5 minutes on a single lead and still can't send a message, move on.**

## Batch Messaging Process

### Sending 10 Messages in 20 Minutes

| Step | Action | Time |
|---|---|---|
| 1 | Open lead sheet. Filter: Segment A, Status = New. | 1 min |
| 2 | Open WhatsApp on phone or WhatsApp Web. | 30 sec |
| 3 | For each lead: copy template, swap [שם] and [שם קבוצה], send. | 90 sec each |
| 4 | After sending: update lead sheet → Status = "Contacted", Last Action Date = today. | 15 sec each |
| 5 | After all 10 sent: set Next Step = "Follow up" and Next Step Date = today + 2. | 2 min |

**Total for 10 messages: ~20 minutes.**

### Pro Tips
- Open all 10 WhatsApp contacts first (save numbers in phone → open chats)
- Have the message template in your clipboard — only change [שם] and [שם קבוצה]
- Don't wait for replies between messages. Send all 10, then check replies later.
- Send between 09:00–11:00 or 14:00–16:00 Israel time for best response rates.
