## CRITICAL landmine fixed today — env files
`.env` (what containers actually load via `env_file: ${APP_ENV_FILE:-.env}`) had drifted STALE vs
`.env.prod` (the real config). A manual `docker compose up -d web` WITHOUT exporting
`APP_ENV_FILE=.env.prod` loaded the stale `.env` → web 502 (env_guard wants `PUBLIC_*_URL`),
trial 14→3, missing `DATA_ENCRYPTION_KEY`, wrong tokens. **Recovered**: web recreated with
`APP_ENV_FILE=.env.prod`; then hardened by making `.env` a byte-copy of `.env.prod` on the box
(backup `.env.bak.20260615-131040`). Always use the export anyway. Full detail in DO_NOT.md.
