# Sunday RecruitBot Execution Bundle

Purpose: prepare one live vacancy campaign for a real client who needs 4 hires.

Use this bundle in this order:
1. Fill the client-facing intake: `vacancy_intake_client.md`
2. Normalize the facts in: `vacancy_intake_template.json`
3. Use message templates from: `CLIENT_MESSAGE_TEMPLATES.md`
4. Finalize copy from: `POSTING_COPY_PACK.md`
5. Load questions from: `SCREENING_PACK.md`
6. Use response templates from: `CANDIDATE_MESSAGE_TEMPLATES.md`
7. Select usable sources from: `source_execution_plan.csv`
8. Track activity in: `pilot_metrics.csv`
9. Update proof in: `case_study_capture.json`
10. Run launch day by: `SUNDAY_EXECUTION_CHECKLIST.md`
11. Check execution reality in: `READINESS_MATRIX.md`

Operational truth:
- manual posting is ready once the vacancy facts are filled;
- assisted/manual Telegram and Facebook execution are usable on Sunday;
- the full bot apply path is still blocked until `RECRUITBOT_TELEGRAM_BOT_TOKEN` is valid.
