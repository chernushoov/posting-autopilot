# Client Onboarding Pack

---

## Onboarding Checklist

Use this for every new pilot client. Copy to your tracking sheet and check off items.

### Pre-Onboarding (Before Call)
- [ ] Client provided email address
- [ ] Client provided list of Facebook groups (links or names)
- [ ] Client provided 1–2 open vacancies for first post
- [ ] Account created in system
- [ ] Client's groups loaded into directory (categorized by city + category)
- [ ] Demo vacancy pre-loaded for the call

### Onboarding Call (15 min)
- [ ] Welcome + set expectations (2 min)
- [ ] Walk through dashboard (1 min)
- [ ] Generate first post together (3 min)
- [ ] Select groups together (2 min)
- [ ] Execute posting queue — post to 3 groups together (5 min)
- [ ] Show results tracking screen (1 min)
- [ ] Confirm they can do it solo (1 min)

### Post-Onboarding (Same Day)
- [ ] Send WhatsApp confirmation: "You're live! Here's what to do tomorrow."
- [ ] Confirm WhatsApp support channel is active
- [ ] Schedule Day 3 check-in reminder
- [ ] Log client in pilot tracking sheet

## Kickoff Call Agenda

**Duration:** 15 minutes
**Channel:** Zoom / Google Meet / phone
**Prep:** Account created, groups loaded, demo vacancy ready

### Minute 0–2: Welcome
> "Welcome to the pilot! Quick overview of what we'll do today: we'll generate your first Facebook post with AI, pick a few groups, post together, and I'll show you the tracking. By the end of this call, you'll have your first post live."

### Minute 2–5: First Post
1. Open the vacancy they provided
2. Click Generate Post
3. Show them the AI output
4. Let them pick a tone
5. Let them edit if they want
6. Click Approve

> "That's your first post. Done. No writing, no formatting."

### Minute 5–7: Group Selection
1. Open Group Directory
2. Show their imported groups + our pre-loaded groups
3. Apply filters relevant to their vacancy
4. Select 3–5 groups

> "These are your target groups. See the activity rating? Focus on 4–5 star groups first."

### Minute 7–12: Post Together
1. Open Posting Queue
2. Walk them through: Copy → Open Group → Paste → Post → Mark Done
3. Do it together for 2–3 groups
4. Let them do 1 group solo while you watch

> "That's the rhythm. Copy, open, paste, post, mark. 15 seconds."

### Minute 12–14: Results Tracking
1. Show the Results screen
2. Explain statuses: Posted → Got Responses → Got CVs → Hired
3. "After you post, come back tomorrow and update the results. That's how we figure out which groups work."

### Minute 14–15: Close
> "You're all set. Post at least one vacancy per day if you can. I'll check in on Day 3. If anything is confusing, message me on WhatsApp — I respond fast. Any questions?"

## Required Client Inputs

### What to Ask For (copy/paste to WhatsApp)

```
כדי להכין את הכל לפני השיחה, אני צריך:

1️⃣ רשימת קבוצות פייסבוק
שלח לי קישורים או שמות של הקבוצות שאתם מפרסמים בהן.
(גם אם זה רק 5-10 קבוצות — זה מספיק להתחלה)

2️⃣ משרה פתוחה לדוגמה
כותרת:
מיקום:
דרישות עיקריות:
שכר (טווח):
הטבות:
דרך הגשה (פרטי / לינק / מייל):

3️⃣ כתובת מייל להרשמה

4️⃣ מתי נוח לשיחת 15 דקות?
(אני גמיש — תבחר/י שעה)
```

### Minimum Viable Input (If Client is Busy)
If they can't provide a full list:
- Email address (mandatory)
- 5 Facebook group links (minimum)
- Job title + city + 3 requirements (minimum for first post)

> "No worries — send me what you have, I'll fill in the rest. We can start with just 5 groups."

## Group Sourcing Template

Use this when helping the client build their group directory.

### Ask the Client
```
כדי לבנות את ספריית הקבוצות שלכם:

1. שלח/י קישורים לקבוצות פייסבוק שאתם כבר מפרסמים בהן
2. ציין/י לכל קבוצה:
   - קטגוריה (הייטק / שירות / כללי / כחול-לבן / עיר ספציפית)
   - האם היא פעילה? (כן / בינוני / לא)
   - הערות (למשל: "צריך אישור מנהל", "אסור לפרסם יותר מפעם ביום")

אם אין לך רשימה מסודרת — שלח מה שיש ואני אסדר.
```

### Group Input Format

| Group Name | Facebook URL | Category | City | Approx. Members | Activity (1–5) | Rules/Notes |
|---|---|---|---|---|---|---|
| | | | | | | |

### If Client Has No Organized List
- Ask them to scroll through their Facebook and screenshot group names
- Or: ask which city/industry they recruit for → we suggest groups from our directory
- Message: "לאיזה תחומים ואיזה ערים אתם מגייסים? אני אציע קבוצות רלוונטיות מהספרייה שלנו."

## Weekly Review Template

Send this every Monday (or Friday) to active pilot clients.

### WhatsApp Weekly Update
```
היי [שם],

סיכום שבועי — Recruit Autopilot:

📊 משרות שפורסמו: [X]
📊 קבוצות בהן פרסמתם: [Y]
📊 קו"ח שהתקבלו: [Z]
📊 קבוצה הכי טובה השבוע: [שם קבוצה] ([N] קו"ח)

💡 המלצה לשבוע הבא:
[recommendation — e.g., "נסו להוסיף 5 קבוצות חדשות באזור חיפה" or "המשרה של QA עבדה טוב — פרסמו שוב בקבוצות שהביאו תוצאות"]

שאלות? אני כאן.
```

### Internal Weekly Review Checklist
For each active pilot, review:
- [ ] How many posts this week?
- [ ] How many unique groups?
- [ ] Any CVs received?
- [ ] Are they tracking results? (If not → nudge)
- [ ] Any support requests?
- [ ] Are they at risk of dropping off?
- [ ] What should I recommend for next week?

## Pilot Success Review Template

Use at end of pilot (Day 13–14). Can be a call or a WhatsApp summary.

### Review Call Script (10 min)

**Open (1 min):**
> "Your pilot ends [tomorrow / in 2 days]. Let's look at what happened."

**Share Data (3 min):**
> "Here are your numbers:
> - Posts published: [X]
> - Groups posted to: [Y]
> - CVs received: [Z]
> - Top performing group: [Name] — [N] CVs
> - Estimated time saved: [N] hours over 14 days"

**Ask for Reaction (2 min):**
> "How does this compare to before? What worked? What didn't?"

**Address Issues (2 min):**
> Listen. Fix what you can. Note what needs product work.

**Close (2 min):**
> "To continue, the Professional plan is 999/month — first month 499 as an early adopter. Want to keep going?"
