# FLOORdsgn — запуск найма на полы (1 страница, turn-key)

Цель пилота: **первый живой прогон системы на нашей реальной вакансии.** Если за неделю
получим N горячих лидов-мастеров с телефоном — это первый пруф, что весь движок работает.

## 0. Что должно быть поднято (один раз)
- `redis`, `postgres`, и 4 процесса: **web + worker + scheduler + bot** (см. `docker-compose.yml`).
- Юзербот залогинен в аккаунт оператора (Telethon session, `data/tg_sessions/company_<id>.session`).
- Env: `RECRUITBOT_TELEGRAM_BOT_TOKEN` (для бота-скрининга), `RECRUIT_OPERATOR_NOTIFY_CHAT`
  (твой Telegram chat_id — туда падают 🔥-лиды). AI-ключ опционален (без него скоринг по правилам).

## 1. Завести вакансию (2 мин)
```bash
python -m scripts.migrate
python ops/floordsgn_hiring_pilot/seed_floor_installer.py
```
Создаст компанию FLOORdsgn + вакансии HE/RU. Запиши `vacancy_id` из вывода.

## 2. Заполнить пробелы (5 мин) — через панель http://localhost:8000
- Открой вакансию → впиши **оплату**, **телефон/WhatsApp** компании (поля помечены `<<...>>`).
- Приложи **1 фото** готового объекта.
- Сузь специализацию, если надо.

## 3. Добавить РЕАЛЬНЫЕ группы (10 мин) — `/sources`
- Добавь 5–15 израильских TG-групп по стройке/работе/ремонту, где сидят мастера.
- Сначала **проверь** каждую (кнопка проверки) — что юзербот может туда писать.
- ⚠️ Не больше, чем позволяют капы: **10 постов/час, 50/день, ночь 23:00–07:00 пауза.**

## 4. Создать кампанию и запустить (2 мин)
- `/campaigns` → новая кампания → вакансия FLOORdsgn → выбери группы → **Start**.
- Scheduler раз в 60с подхватит и начнёт постить с задержкой 30–120с между группами.

## 5. Что увидишь
- В группах появляется пост с фото + кнопка/ссылка «откликнуться».
- Мастер жмёт → личка бота → 4 вопроса → телефон → скоринг → если ≥40 + телефон:
  **🔥 тебе в Telegram падает лид** (имя, телефон, опыт, выжимка, WhatsApp-ссылка).

## 6. Концирж-подстраховка (важно на пилоте)
- Кто ответит **в комментариях группы** (а не в боте) — движок не ловит. **Раз в день
  пробегись по группам руками** и подбери таких.
- FB/сторис на этом пилоте не трогаем — только TG-группы.

## 7. Снять пруф
- Скрины 🔥-лидов в Telegram + цифра «X откликов / Y квалифицированных за Z дней».
- Это наш первый кейс — он же продающий аргумент для внешних клиентов (недвижка и т.д.).

---
**Где затыки вероятнее всего:** (1) юзербот не залогинен / сессия слетела; (2) группы не
проверены и постинг молча не идёт; (3) `RECRUIT_OPERATOR_NOTIFY_CHAT` не задан → лиды
скорятся, но уведомление не приходит. Проверь эти три в первую очередь.
