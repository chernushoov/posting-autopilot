## Review After 10 Sends

**When:** After your first 10 messages have been out for 48 hours.
**Time:** 15 minutes.

### Count These

| Metric | Count | Benchmark |
|---|---|---|
| Messages sent | ___ | 10 |
| Delivered | ___ | Should be 10 |
| Read (WhatsApp) | ___ | Should be 7+ |
| Responses received | ___ | Target: 3+ |
| HOT responses | ___ | Target: 1+ |
| Demos booked | ___ | Target: 1+ |
| NOT FIT responses | ___ | Note if >3 → wrong targeting |

### Answer These

**1. "Which channel got the best response rate?"**
- WhatsApp vs email vs FB messenger vs LinkedIn
- **Action:** shift next batch toward the winning channel

**2. "Which message type got the best response?"**
- Personalized with FB group reference vs generic sector reference vs qualifying
- **Action:** use the winning type more in wave 2

**3. "What did responders have in common?"**
- Agency size? Sector? How I found them?
- **Action:** source more leads that match responding profile

**4. "What did non-responders have in common?"**
- Reached via email only? Directory-sourced? No FB confirmation?
- **Action:** reduce time on this profile in wave 2

**5. "Did anyone say something I didn't expect?"**
- New objection? New use case? Feature request?
- **Action:** add to objection handling if needed; note for product

## Review After 3 Demos

**When:** After your first 3 demos.
**Time:** 15 minutes.

### Answer These

**1. "What was the first question they asked?"**
- If 2/3 asked the same question → put the answer in your opening pitch

**2. "What was the 'aha' moment?"**
- When did they lean in? AI generation? Posting speed? Results tracking?
- **Action:** lead with that in future demos

**3. "What objection came up most?"**
- **Action:** preemptively address it before it's raised in next demos

**4. "Did they commit to a pilot?"**
- If 2/3 → great, keep going
- If 1/3 → what blocked the other 2? Fix it.
- If 0/3 → something is off. Is the demo showing real value? Is the pilot ask clear?

**5. "What would I do differently in the next demo?"**
- Write one sentence. Apply it.

## How to Refine Message Selection for Wave 2

### If WhatsApp + FB Group Reference Worked Best
- Source next leads directly from Facebook groups (scroll and find posters)
- Always include the group name in the first line
- Spend 10 min on FB enrichment before each send batch

### If Email Worked Surprisingly Well
- Prioritize leads where you have email but no phone
- Test 2 subject lines against each other (track which gets more opens)

### If Qualifying Messages ("Do You Post on FB?") Got Good Engagement
- Use this for all Tier 2/3 leads
- It filters fast and doesn't waste your time on non-FB agencies

### If Response Rate Was Below 15% Overall
- The problem is targeting, not messaging
- Stop messaging from directories/LinkedIn
- Source exclusively from Facebook groups where you SEE them posting
- Every lead in wave 2 must be a confirmed FB group poster

## What Counts as Real Traction vs Noise

### Real Traction

| Signal | Why It's Real |
|---|---|
| Someone books a demo after your first message | Product interest confirmed |
| Someone agrees to pilot after demo | Activation imminent |
| Pilot client posts 3+ vacancies in first 3 days | They're using it, not just testing |
| Pilot client asks "how do I add more groups?" | Expanding — product is working |
| Someone asks "how much does this cost?" | Buying intent |
| Someone refers you to another agency | They see value worth sharing |
| Pilot client says "this saves time" in their own words | Value validated |
| You get a CV tracked back to a group posting | End-to-end value proven |

### Noise (Do Not Celebrate)

| Signal | Why It's Noise |
|---|---|
| "Interesting" with no next step | Polite brush-off until proven otherwise |
| High read rates but no replies | Message is opened, not compelling |
| Someone says "send info" but never responds after | Brush-off |
| Pilot client logs in once and never returns | Activation failed |
| Someone asks lots of questions but won't book a demo | Information collector, not buyer |
| You source 50 leads but only message 10 | Research procrastination |
| You rewrite your message 5 times before sending | Perfectionism procrastination |

## Wave 1 → Wave 2 Transition Checklist

Run this after 48 hours of wave 1 sends + at least 1 demo.

```
□ Counted: responses / demos / pilots from wave 1
□ Identified best-performing channel
□ Identified best-performing message type
□ Identified most common objection
□ Decided: source more from FB groups / keep same approach / adjust message
□ Sourced 10 new leads for wave 2 (preferably from live FB group scouting)
□ Wrote/selected message type for wave 2
□ Set Day 1 send target for wave 2
```

**Wave 2 should be better than wave 1.** If it's not, you're not learning — go back to the review questions.
