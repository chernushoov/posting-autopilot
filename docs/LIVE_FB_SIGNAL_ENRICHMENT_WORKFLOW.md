# Live Facebook Signal Enrichment Workflow

---

## Purpose

The strongest outreach message references a specific Facebook group where you saw the agency posting. This workflow gets you those references in 10–15 minutes.

---

## When to Do This

- **Before sending wave 1:** spend 10 min after completing contact research
- **Before sending wave 2:** spend 10 min to find fresh leads
- **Any time response rates drop:** enriched messages convert 2x vs generic

---

## The 10-Minute Workflow

### Minute 0–2: Open Facebook and Search

Open Facebook. Search these queries ONE AT A TIME. Join the group if not already a member. Click "New Posts" or sort by recent.

**Priority queries (use these first):**
```
1. דרושים הייטק
2. דרושים תל אביב
3. דרושים עובדים
```

You should already be a member of these from the sourcing sprint. If not, join the top 2 groups per query.

### Minute 2–8: Scroll and Capture

For each group, scroll the last 24–48 hours of posts.

**What you're looking for:**

| Signal | What to Capture | How It Helps |
|---|---|---|
| Post from one of your 20 leads | Screenshot + group name + post text snippet | "ראיתי את הפוסט שלכם בקבוצת [שם] — [quote a detail]" |
| Post from an agency NOT on your list | Agency name + poster name + group + profile link | New lead, Tier 1, add to batch |
| Same person posting in 2+ groups | Note both groups | "ראיתי שאתם מפרסמים ב[קבוצה 1] וגם ב[קבוצה 2]" |
| Copy-paste post (identical text, no tailoring) | Note it | "שמתי לב שאתם מפרסמים אותו טקסט בכמה קבוצות" |
| Post with bad formatting or generic text | Note it | Shows they'll value AI-generated posts |
| Post with "URGENT" / "דחוף" / "HOT" | Note it | High-pressure hiring = acute need for speed |

**Capture format (paste into a note or sheet):**
```
Agency: ___
Poster: ___
Group: ___
What I saw: ___
Profile link: ___
Already on my list? Y/N
```

### Minute 8–10: Upgrade Your Messages

For each existing lead where you found live evidence:

**Before:**
```
ראיתי ש-[agency] פעילים בגיוס הייטק...
```

**After:**
```
ראיתי את הפוסט שלכם בקבוצת "דרושים הייטק תל אביב" — משרת [job title] 👋
```

The upgrade is: **generic agency reference → specific group + specific post detail.**

---

## Enrichment Decision Matrix

| What You Found | Impact on Message | Action |
|---|---|---|
| Found their post in a specific group | HIGH — use group name and post detail | Rewrite first line of message |
| Found their post is copy-paste across groups | HIGH — use the copy-paste observation | Change hook to "שמתי לב שאתם מפרסמים אותו פוסט בכמה קבוצות" |
| Found them posting urgently / high volume | MEDIUM — emphasizes speed value | Add "נראה שיש לכם הרבה משרות פתוחות — " before the pitch |
| Found a NEW agency not on your list | HIGH — new Tier 1 lead | Add to batch. Write fresh personalized message with group reference. |
| Didn't find any of your 20 leads in groups | LOW — no change needed | Keep existing messages as-is. Try again tomorrow in different groups. |

---

## How to Update Existing Messages

### Template: Converting Generic to Enriched

**Generic first line:**
```
ראיתי ש-[agency] פעילים בגיוס [sector]...
```

**Enriched first line options:**

**Option A — Specific group reference:**
```
ראיתי את הפוסט שלכם בקבוצת "[group name]" — [one detail from their post] 👋
```

**Option B — Multi-group observation:**
```
ראיתי שאתם מפרסמים ב"[group 1]" ו"[group 2]" — הרבה פרסום ידני, נכון?
```

**Option C — Copy-paste observation:**
```
שמתי לב שאתם מעלים אותו פוסט בכמה קבוצות — אפשר לחסוך את הזמן הזה 👇
```

**Option D — Urgent posting observation:**
```
ראיתי שאתם מחפשים [role] בדחיפות ב"[group name]" — יש דרך מהירה יותר לפרסם.
```

**Rest of the message stays the same.** Only the first 1–2 lines change.

---

## Hard Rules

| Rule | Why |
|---|---|
| Spend MAX 15 minutes on this | Diminishing returns after that |
| Do NOT join more than 3 new groups per session | Facebook may flag rapid group joins |
| Do NOT comment on their posts in the group | Looks weird / desperate |
| Do NOT screenshot and send their post to them | Feels invasive |
| DO reference the group name and a general detail | Proves you're real without being creepy |
| If you find 0 leads in 10 minutes, stop | Try different groups tomorrow |

---

## New Leads Found During Enrichment

If you find agencies posting in groups that are NOT on your current list:

1. Add to lead sheet immediately
2. Mark as Tier 1 (confirmed poster, specific group reference)
3. Capture: agency name, poster name, profile link, group name, what they posted
4. Write a message using Option A above
5. Research contact (phone/WhatsApp) using the 5-step contact workflow
6. Add to the top of your next send batch

**These leads are your highest-converting prospects.** They should jump the queue ahead of any Bucket 2/3 leads.
