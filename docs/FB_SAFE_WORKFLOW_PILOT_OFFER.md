## Pilot Signup Flow

### Step 1: Initial Contact
Recruiter receives pitch (WhatsApp/email/Telegram) and expresses interest.

### Step 2: Quick Qualification
5-minute call or WhatsApp exchange:
- How many vacancies per week?
- How many Facebook groups?
- Current process (manual / autoposter)?
- Number of recruiters?

### Step 3: Onboarding Session (15 minutes)
1. Create account
2. Import their Facebook groups (we help)
3. Generate first post together
4. Execute first posting queue together
5. Show results tracking

### Step 4: Self-Service Pilot
Recruiter uses tool independently for 14 days.
WhatsApp support available for questions.

### Step 5: Pilot Review
10-minute call:
- Share usage stats
- Discuss results
- Present continuation offer
