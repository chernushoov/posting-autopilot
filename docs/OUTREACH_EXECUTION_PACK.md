## Founder WhatsApp Outreach Script

### Cold — Saw Their Activity in Facebook Groups
```
היי [שם],

ראיתי שאתם מפרסמים משרות בקבוצות פייסבוק — [שם קבוצה].

בניתי כלי שעושה את זה 5x יותר מהר:
🔹 AI כותב פוסט בעברית — 3 שניות
🔹 ספריית קבוצות עם דירוגי ביצועים
🔹 מעקב מלא — מאיזה קבוצה הגיעו קו"ח

בלי בוטים. בלי סיכון חסימה. המגייס תמיד לוחץ "פרסם" בעצמו.

יש לי דמו של 5 דקות — מעניין?
```

### Cold — Don't Know Their Process
```
היי [שם],

אני רואה שאתם מגייסים ב[תחום/עיר].

שאלה מהירה — מפרסמים משרות בקבוצות פייסבוק?

אם כן — בניתי כלי שחותך את הזמן ב-80% ומוסיף מעקב מלא. בלי אוטומציה, בלי סיכון חסימה.

אם לא — סליחה על ההפרעה, יום טוב 😊
```

### Cold — After Facebook Ban Story in Group/Forum
```
היי [שם],

קראתי על הבעיות שלכם עם חסימות בפייסבוק.

בניתי כלי בדיוק בגלל הסיפורים האלה — פרסום משרות בקבוצות פייסבוק, מהיר, עם AI, אבל בלי שום אוטומציה שנוגעת בחשבון.

המגייס תמיד מפרסם בעצמו. אפס סיכון.

אפשר 5 דקות? אראה לך איך זה עובד.
```

## Founder Email Outreach Script

### Subject Lines
```
A: "הכלי שמחליף את האוטופוסטרים — בלי הסיכון"
B: "פרסום משרות בפייסבוק: 5x מהר יותר, 0 סיכון חסימה"
C: "מגייסים דרך FB groups? שווה 5 דקות"
```

### Email Body — Direct
```
שלום [שם],

קצר ולעניין:

מגייסים ישראלים מפרסמים עשרות משרות בקבוצות פייסבוק כל יום.
רובם עושים את זה ידנית. חלקם משתמשים באוטופוסטרים ומסתכנים בחסימה.

בניתי Recruit Autopilot — כלי שעוזר לפרסם מהר, עם AI, עם מעקב, ובלי שום סיכון:

1. AI כותב פוסט בעברית (3 שניות)
2. ספריית קבוצות חכמה (200+ קבוצות)
3. תהליך פרסום מהיר (15 שניות לקבוצה)
4. מעקב מלא (קו"ח לפי קבוצה)

המגייס תמיד לוחץ "פרסם" בעצמו. אפס אוטומציה. אפס סיכון.

14 יום ניסיון חינם, בלי כרטיס אשראי.

אפשר 5 דקות השבוע?

[שם]
Recruit Autopilot
```

## Warm Intro Message

### Ask Someone to Introduce You
```
היי [שם ממליץ],

תודה שהסכמת לקשר!

אפשר לשלוח ל[שם היעד] הודעה כזו?

---

"היי [שם], רציתי לקשר אותך עם [שם הפאונדר] — הוא בנה כלי שעוזר למגייסים לפרסם משרות בקבוצות פייסבוק מהר יותר, עם AI ומעקב. חשבתי שזה רלוונטי לכם. [שם הפאונדר], קח מכאן."

---

או שתקשר ישירות ואני אעקוב. מה יותר נוח?
```

### After Warm Intro — First Message to Prospect
```
היי [שם],

[שם הממליץ] קישר בינינו — תודה שהסכמת לשמוע.

בניתי כלי שעוזר לחברות גיוס לפרסם משרות בקבוצות פייסבוק:
🔹 AI כותב פוסטים בעברית
🔹 ספריית קבוצות חכמה עם דירוגי ביצועים
🔹 פרסום מהיר ומעקב מלא
🔹 בלי שום אוטומציה — אפס סיכון חסימה

אפשר 5 דקות השבוע? יש דמו קצר שמסביר הכל.
```

## Post-Demo Follow-Up

### Same Day (Within 2 Hours)
```
היי [שם],

תודה על הזמן! 🙏

סיכום מהיר:
✅ AI כותב פוסטים — בלי כתיבה ידנית
✅ ספריית קבוצות עם דירוגים — בלי ניחושים
✅ מעקב מלא — לראשונה תדעו מאיפה מגיעים קו"ח
✅ אפס סיכון חסימה

הצעד הבא:
14 יום פיילוט חינם. אני מכין את הכל — 15 דקות הדרכה ומפרסמים ביחד את המשרה הראשונה.

מתי נוח?
```

## Rejection Recovery Message

### After "Not Interested"
```
היי [שם],

תודה על הכנות. לפני שאני נעלם — שאלה אחת:

מה הסיבה העיקרית? (ככה אני יכול להשתפר)

א. לא מפרסמים בפייסבוק
ב. מרוצים מהתהליך הקיים
ג. לא הזמן הנכון
ד. משהו אחר

מעריך את הזמן 🙏
```

### After "Not Now" / "Maybe Later"
```
היי [שם],

בסדר גמור. אני שומר את ההצעה פתוחה.

שאלה אחת — מתי הייתם רוצים שאחזור? אני אשלח תזכורת ולא אפריע עד אז.

א. חודש
ב. רבעון
ג. אל תחזור
```

## Referral Ask Message

### After Demo (Whether They Convert or Not)
```
היי [שם],

שאלה אחרונה — מכירים סוכנות גיוס אחרת שמפרסמת בקבוצות פייסבוק?

אשמח להכרות. ואם הם ייכנסו לפיילוט, אני נותן לכם חודש חינם על ההפניה.

תודה!
```

### Standalone Referral Ask (Existing Contact)
```
היי [שם],

אני מחפש סוכנויות גיוס שמפרסמות משרות בקבוצות פייסבוק.

מכיר/ה מישהו שכדאי שאני אדבר איתו?

אשמח לכל הפניה — ויש תגמול על כל לקוח שנכנס 😊

תודה!
```

## Outreach Daily Execution Plan

### Morning Routine (30 min)

| # | Action | Time |
|---|---|---|
| 1 | Check pilot clients — any need attention? | 5 min |
| 2 | Send scheduled follow-ups (Day 3 / Day 7 messages) | 5 min |
| 3 | Send 5 new cold WhatsApp messages | 10 min |
| 4 | Post in 1 Telegram recruitment channel | 5 min |
| 5 | Send 3 cold emails | 5 min |

### Weekly Targets

| Metric | Target |
|---|---|
| Cold WhatsApp messages sent | 25 |
| Cold emails sent | 15 |
| Telegram posts/DMs | 5 |
| Demos booked | 3–5 |
| Demos completed | 2–3 |
| Pilots started | 1–2 |

### Where to Find Prospects

| Source | How | Volume |
|---|---|---|
| Facebook recruitment groups | Search for agencies posting vacancies → note the poster's profile/agency | High |
| LinkedIn | Search "recruiter" + "Israel" → check if they mention Facebook | Medium |
| Google | "סוכנות גיוס" + city name → find agency websites → find contact | Medium |
| AllJobs / Drushim | Check which agencies are active → cross-reference on Facebook | Medium |
| Referrals | Ask every demo/pilot client for 1–2 introductions | High quality |
| Telegram HR groups | Post in relevant groups, DM active recruiters | Medium |
