# Demo Booking & Response Handling

---

## Response Classification

When a prospect replies, classify immediately and respond within 5 minutes.

### Classification Table

| Response Type | Examples | Priority | Next Action |
|---|---|---|---|
| **HOT — Interested** | "כן, מעניין" / "אפשר דמו" / "מתי?" / "ספר לי עוד" | 🔴 Now | Book demo immediately |
| **WARM — Curious** | "מה זה?" / "כמה זה עולה?" / "איך זה עובד?" | 🔴 Now | Answer in 2 lines → push for demo |
| **MAYBE LATER** | "לא עכשיו" / "אולי בחודש הבא" / "תחזור אליי" | 🟡 Set reminder | Acknowledge + set exact follow-up date |
| **NOT NOW** | "עסוק" / "לא הזמן" / "אין לי זמן" | 🟡 Set reminder | "מתי נוח שאחזור?" → set date |
| **NOT FIT** | "לא מפרסמים בפייסבוק" / "לא רלוונטי" | ⚪ Close | Thank + ask for referral |
| **REFERRAL** | "דבר עם X" / "יש לי חבר שעושה את זה" | 🔴 Now | Get the intro. Thank. Follow up on referral same day. |
| **NEGATIVE** | "לא תפריע" / "spam" / block | ❌ Archive | Remove from list. Don't contact again. |

## Response Playbooks

### HOT — They Want a Demo

**Step 1: Lock a time (within 60 seconds)**
```
מעולה! מתי נוח ל-5 דקות?

יש לי פנוי:
• היום ב-[X]
• מחר ב-[X]
• [מחרתיים] ב-[X]

מה עדיף?
```

**Step 2: After they pick a time**
```
מצוין, קבענו ל-[יום] ב-[שעה].

אני אשלח לינק לזום.
נתראה! 👋
```

**Step 3: Send calendar invite or Zoom link immediately.**

---

### WARM — Curious, Asking Questions

**Rule: answer in 2 lines max, then push for demo.**

| Their Question | Your Response |
|---|---|
| "מה זה?" | "כלי שעוזר למגייסים לפרסם בקבוצות פייסבוק — מהר ועם מעקב. בלי אוטומציה. אפשר 5 דקות ואני מראה?" |
| "כמה עולה?" | "14 יום חינם, בלי כרטיס אשראי. אחרי זה מ-499 ₪/חודש. אבל שווה לראות קודם — 5 דקות?" |
| "איך זה עובד?" | "AI כותב פוסט → בוחרים קבוצות → מפרסמים ידנית (15 שניות) → הכל נעקב. רוצה לראות? 5 דקות." |
| "מה ההבדל מאוטופוסטר?" | "אנחנו לא נוגעים בפייסבוק — אתה תמיד מפרסם בעצמך. אפס סיכון חסימה. פלוס מעקב שאין לאף אוטופוסטר. דמו של 5 דקות?" |
| "מי עוד משתמש?" | "אנחנו בשלב מוקדם — 20 סוכנויות בפיילוט הראשון. אתם יכולים להיות מהראשונים ולהשפיע על המוצר. דמו?" |

**Pattern: short answer + "רוצה לראות? 5 דקות."**

### MAYBE LATER

```
בסדר גמור 👍

מתי נוח שאחזור? ככה לא אפריע סתם.

א. שבוע הבא
ב. חודש
ג. אחרי פסח / אחרי החגים / [relevant timing]
```

**After they answer: set exact date in lead sheet. Follow up on that date. Do not send anything in between.**

---

### NOT FIT

```
הבנתי, תודה על הכנות!

שאלה אחרונה — מכירים סוכנות גיוס שכן מפרסמת בקבוצות פייסבוק?
אשמח להפניה 🙏
```

**If they refer someone: treat the referral as Segment A, Tier 1. Contact same day.**

---

### REFERRAL

```
תודה ענקית! 🙏

אפשר שתקשר בינינו? או שאפנה אליו ואגיד ש[שם] הפנה?
```

**Then:**
```
היי [שם הנמען],

[שם הממליץ] הפנה אותי אליך.

בניתי כלי שעוזר למגייסים לפרסם משרות בקבוצות פייסבוק — מהר, עם AI, עם מעקב. בלי סיכון חסימה.

אפשר 5 דקות?
```

## Scheduling a Demo

### What to Send When Booking

**Option A: They suggest a time**
```
מצוין, קבענו ל-[יום] ב-[שעה].
אני אשלח לינק.
```

**Option B: You offer times**
```
מתי נוח? יש לי:
• [יום] ב-[שעה]
• [יום] ב-[שעה]
• [יום] ב-[שעה]
```

**Option C: They're vague ("this week sometime")**
```
מה לגבי [מחר/יום ספציפי] ב-10:00? 5 דקות ונסיים.
```

### After Booking — Confirm + Send Link
```
קבענו ל-[יום, תאריך] ב-[שעה].

הנה לינק: [zoom/meet link]

זה 5 דקות — שיתוף מסך ואני מראה איך עובד הכלי.

נתראה! 👋
```

## Demo Reminders

### 1 Hour Before Demo
```
היי [שם],

תזכורת — נפגשים עוד שעה ב-[שעה] 👋

הלינק: [zoom/meet link]
```

### 5 Minutes Before (If They Haven't Joined)
```
היי, אני בזום — מחכה לך 😊
[link]
```

### No-Show (15 Minutes After Scheduled Time)
```
היי [שם],

חיכיתי בזום — אולי לא הלך הזמן? 😊

אפשר לקבוע מחדש?
• [זמן 1]
• [זמן 2]
```

## Post-Demo: Next Step Push

### Immediately After Demo (Within 1 Hour)

**If they seemed interested:**
```
היי [שם],

תודה על 5 הדקות! 🙏

סיכום מהיר:
✅ AI כותב פוסטים — בלי כתיבה ידנית
✅ ספריית קבוצות עם דירוגים
✅ מעקב מלא על תוצאות
✅ אפס סיכון

הצעד הבא: 14 יום פיילוט חינם. אני מכין הכל — 15 דקות הדרכה ומפרסמים ביחד.

מתי נוח להתחיל?
```

**If they were lukewarm:**
```
היי [שם],

תודה על הזמן! 🙏

אם רוצים לנסות — 14 יום חינם, בלי התחייבות. אני מכין את הכל ונפרסם ביחד את המשרה הראשונה.

אם יש שאלות — אני כאן.
```

**If they said "I need to think":**
```
היי [שם],

תודה על הדמו! בלי לחץ.

שאלה אחת — מה הדבר העיקרי שתרצה לוודא לפני שמתחילים?

ככה אני יכול לעזור.
```

## Post-Demo Follow-Up Cadence

| Timing | Action | Message |
|---|---|---|
| Same day | Send summary + pilot offer | See above |
| Day +2 | Soft follow-up if no reply | "היי [שם], חשבת על הפיילוט?" |
| Day +5 | Direct push | "יש לי עוד כמה מקומות בפיילוט — רוצה לתפוס?" |
| Day +7 | Final touch | "היי, נסיון אחרון 😊 אם רוצה לנסות — 14 יום חינם, בלי התחייבות. אם לא — בהצלחה!" |

**After Day 7 with no response: archive. Move on. You can retry in 60 days.**

## Demo Prep Checklist (2 Minutes Before Each Demo)

- [ ] Product/demo ready to screen share
- [ ] Have a vacancy loaded (real or realistic)
- [ ] Group directory showing 15+ groups
- [ ] Know the prospect's name, agency, what you saw them post
- [ ] Zoom/Meet link sent and confirmed
- [ ] Lead sheet open to update immediately after
