# Founder Daily Execution Sheet

---

## Morning Start (5 Minutes)

Open these:
1. Lead sheet → "Daily Actions" tab (filtered: Next Step Date = today)
2. WhatsApp
3. Calendar (any demos today?)

Ask yourself:
- **Who needs a response today?** → Reply first.
- **Who needs a follow-up today?** → Send follow-up.
- **Any demos today?** → Prep 2 min before.

---

## Daily Action Blocks

### Block 1: Respond + Follow Up (15 min) — Do First

| # | Action | Target |
|---|---|---|
| 1 | Reply to all WhatsApp/email responses from yesterday | All pending replies |
| 2 | Send scheduled follow-ups (leads where Next Step Date = today) | 3–5 follow-ups |
| 3 | Classify any new responses (HOT / WARM / MAYBE / NOT FIT) | All new responses |
| 4 | Book demos for anyone who said yes | Every hot lead |

**Rule: never let a "yes" or "interested" sit unanswered for more than 2 hours.**

### Block 2: New Outreach (15 min)

| # | Action | Target |
|---|---|---|
| 1 | Send new WhatsApp messages to Segment A leads | 3–5 new messages |
| 2 | Send new WhatsApp messages to Segment C leads (qualifying) | 2–3 new messages |
| 3 | Send emails to leads where you only have email | 1–2 emails |

**Total new outreach per day: 5–8 messages.**

### Block 3: Demos (As Scheduled)

| # | Action | Target |
|---|---|---|
| 1 | Prep for demo (2 min before: load vacancy, check their info) | Every scheduled demo |
| 2 | Run demo (5–15 min) | |
| 3 | Send post-demo follow-up (within 1 hour) | Every completed demo |

### Block 4: Pilot Support (If Active Pilots — 10 min)

| # | Action | Target |
|---|---|---|
| 1 | Check if pilot clients posted today | Every active pilot |
| 2 | Send check-in if needed (Day 1, 3, 7, 12 per pilot timeline) | Scheduled check-ins |
| 3 | Answer any support questions | As needed |

### Block 5: End of Day (5 min)

| # | Action |
|---|---|
| 1 | Update lead sheet: all statuses, next steps, next step dates |
| 2 | Count today's numbers (see KPI section below) |
| 3 | Set tomorrow's actions: who to follow up with, who to outreach |

## Daily Outreach Targets

| Metric | Minimum | Good | Great |
|---|---|---|---|
| **New messages sent** | 3 | 5 | 8+ |
| **Follow-ups sent** | 2 | 4 | 6+ |
| **Responses received** | 1 | 2 | 3+ |
| **Demos booked** | 0 | 1 | 2 |
| **Demos completed** | 0 | 1 | 1+ |
| **Pilots started** | 0 | 0 | 1 |

**If you hit "Minimum" every day for a week, you'll have enough pipeline. "Good" gets you to 2–3 pilots in 10 days.**

## What to Review at End of Day

### 3 Questions (30 Seconds Each)

**1. "Did I move anyone forward today?"**
- A response? A demo booked? A pilot started?
- If yes → good. If no → why? Not enough outreach? Wrong targets?

**2. "Is anyone stuck in my pipeline?"**
- Anyone I contacted 3+ days ago with no response and no follow-up sent?
- Anyone who said "maybe" but I haven't followed up?
- Fix these tomorrow morning.

**3. "Do I have enough leads to message tomorrow?"**
- If yes (3+ unsent leads) → good.
- If no → spend 30 min sourcing tomorrow before outreach.

## What Counts as Progress vs Noise

### Real Progress
| Signal | Why It Matters |
|---|---|
| Response to outreach | Conversation started |
| Demo booked | Pipeline advancing |
| Demo completed | Opportunity created |
| Pilot started | Product being tested |
| Client posts using the tool | Activation — they're using it |
| CVs received through tracked groups | Value delivered |
| "Can I sign up?" / "How much?" | Buying intent |
| Referral to another agency | Network effect starting |

### Noise (Don't Mistake for Progress)
| Signal | Why It's Not Progress |
|---|---|
| Sourcing 50 more leads when you have 20 uncontacted | Procrastination |
| Rewriting message templates for the 3rd time | Perfectionism |
| Building a more complex spreadsheet | Avoiding outreach |
| Reading about Facebook group posting strategies | Avoiding outreach |
| Planning outreach instead of doing outreach | Avoiding outreach |
| Someone read your message but didn't reply | Not a response |
| "Interesting" with no next step | Not commitment |

## The Founder's Daily Schedule (Suggested)

| Time | Action | Duration |
|---|---|---|
| 09:00 | Open lead sheet + WhatsApp. Reply to responses. | 10 min |
| 09:10 | Send follow-ups for today. | 5 min |
| 09:15 | Send 5 new outreach messages. | 15 min |
| 09:30 | Done with outreach. Switch to other work. | — |
| ~11:00 | Check for responses. Reply. Book demos if any. | 5 min |
| ~14:00 | Run any scheduled demos. | 15 min per demo |
| ~14:30 | Send post-demo follow-ups. | 5 min |
| ~16:00 | Final response check. Reply to anything new. | 5 min |
| 17:00 | End-of-day: update sheet, count KPIs, set tomorrow's actions. | 5 min |

**Total founder time per day: 45–75 minutes** (excluding demos).
