# Raw Response Intake Guide

Use `raw_response_intake.csv` as the first landing sheet for manual inbound responses.

## When to log here
- a candidate replies in Telegram manually
- a candidate sends a Facebook message
- a source owner forwards a contact
- any inbound lead arrives before full structured screening starts

## Rule
- log the response immediately
- then move the person into `candidate_pipeline.csv` when processing starts
- do not keep operational truth only in chat apps
